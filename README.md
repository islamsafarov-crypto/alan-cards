# Alan

App for ASD kids to develop speaking skills.

Названо в честь моего сына Алана.

Приложение для детей с особенностями речевого развития (алалия, расстройства аутистического спектра): понимание предлогов и вопросов через сочетание **слова + картинки + надписи**.

## Что внутри

- **Куда положить?** — предлоги НА, В, ПОД, РЯДОМ С, ИЗ. Ребенок слушает инструкцию и перетаскивает предмет пальцем.
- **Вопросы** — «Что это?», «Где?», «Кто это?», «Что делает?» (по фото семьи, которые родители загружают на своем устройстве).
- **Уровни содержания** и **ступени подсказок** внутри каждого уровня; переход на следующий уровень предлагается после 8 верных ответов из 10 без подсказок.
- **Раздел для родителей** (удерживать шестеренку): уровни, фото, голос, журнал ответов.

Все данные (прогресс, журнал, фото) хранятся только на устройстве. Приложение ничего никуда не отправляет.

## Как открыть

Откройте ссылку GitHub Pages в Safari на iPad и выберите «Поделиться» → «На экран Домой».
